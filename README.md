# 南溪 AI 获客系统

抖音评论区获客智能体系统 —— 通过评论区回复高意向客户，引导主动私信，实现从线索到成交的全流程管理。

## 核心策略

**评论区回复为主，主动私信为辅** —— 在高意向评论下用钩子话术回复，勾起用户兴趣后引导其主动私信，降低账号限流风险。

## 功能模块

### 获客域
- **线索池** — 采集/手动录入线索，意向评分，状态机管理
- **评论回复任务** — 高意向评论分配话术，状态追踪（待回复→已回复→对方追评/私信）
- **私信收件箱** — 用户主动私信承接，AI 建议回复
- **私信发送队列** — 主动私信限流队列，账号健康度联动
- **话术库** — 10 行业 × 5 分类，A/B 变体自动切换（R2 规则）
- **抖音账号管理** — 多账号健康分五维计算，限流状态机
- **采集配置** — MediaCrawler 对接，关键词/对标账号/指定视频采集

### 客户域
- **客户与商机** — 7 阶段流水线，成交录入 ≤3 次点击
- **今日跟进** — 逾期/今日/即将三段筛选，完成自动消失
- **线索→客户转化** — 加微后自动联动

### 分析域
- **转化漏斗** — 六级漏斗 + 成本核算 + 14 天趋势
- **归因分析** — 6 触点归因 + 内容榜
- **合规引擎** — R1/R2/R3 规则，安全模式一键切换
- **工作台** — 今日总览 + 预警 + 活动流

### 系统能力
- AI 大模型接入（DashScope / 豆包双 Provider）
- 多账号调度（轮询/权重/健康度优先）
- 数据导出与报表
- 通知提醒（7 种类型自动触发）
- 数据备份与恢复
- 系统监控（API 统计 + 性能指标）
- Electron 桌面端（CDP 私信执行器）

## 快速开始

### 后端

```bash
cd backend
pip install -r requirements.txt  # 或 uv sync
$env:MEDIA_CRAWLER_AUTOSTART="false"
$env:DB_PATH="D:\.data\lead_system.db"
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

### 前端

```bash
cd frontend
python -m http.server 8080
# 打开 http://127.0.0.1:8080
```

### 桌面端

```bash
cd desktop
npm install
npm start
```
