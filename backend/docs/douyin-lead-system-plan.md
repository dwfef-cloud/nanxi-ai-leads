# 抖音获客系统实施方案

## 定位
抖音公开线索发现 + 私信辅助触达 + 轻量 CRM

## 推荐技术底座
- 采集：MediaCrawler
- 浏览器自动化：Playwright 或 Patchright
- 后端：FastAPI
- 数据库：PostgreSQL
- 队列：Redis
- 前端：React 或 Vue

## 模块划分
1. 采集层：关键词、视频、评论、用户
2. 清洗层：去重、过滤、标签、评分
3. 客户层：线索池、跟进状态、备注
4. 消息层：会话、草稿、人工确认发送
5. 任务层：采集、同步、发送、重试
6. 统计层：回复率、转化率、账号健康度

## 开发顺序
1. 先搭线索采集和入库
2. 再搭线索列表和筛选
3. 再做私信草稿与人工确认
4. 最后补任务调度和统计

## 第一版交付物
- 项目骨架
- 数据模型
- 采集任务接口
- 线索列表页面
- 私信草稿页面
- 发送日志
