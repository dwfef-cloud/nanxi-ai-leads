客户机如何接入

客户机上运行的获客系统只需在设置里填两项：后台地址 与 密钥。 启动时调「激活」，之后每 5 分钟调一次「心跳」上报用量。 被吊销或过期时心跳返回 stop=true，客户端应停止采集与发送。

1. 首次激活（绑定机器）
POST /admin/api/activate
Content-Type: application/json

{
  "licenseCode": "ALS-P2K8-7QMX3RTB-9D4F",
  "machineId": "客户机唯一标识（建议取主板+MAC 的哈希）",
  "hostname": "DESKTOP-01",
  "appVersion": "1.0.0"
}
→ { "ok": true, "status": "active", "plan": "pro",
    "expiresAt": "2027-11-13T00:00:00+00:00",
    "dailyQuota": 500 }
2. 周期心跳（续活 + 上报用量）
POST /admin/api/heartbeat
Content-Type: application/json

{
  "licenseCode": "ALS-P2K8-7QMX3RTB-9D4F",
  "machineId": "同上",
  "hostname": "DESKTOP-01",
  "appVersion": "1.0.0",
  "usage": { "day": "2026-11-13",
             "leads": 12, "comments": 8, "dms": 3,
             "logins": 1, "actions": 23 }
}
→ { "ok": true, "stop": false, "usedToday": 23, "overQuota": false }
3. 离线校验（不联网也能判断真伪与到期）
GET /admin/api/verify?code=ALS-P2K8-7QMX3RTB-9D4F

密钥内含套餐与到期日，并用 HMAC 签名防伪造；
离线可用，联网只用于吊销与用量上报。
