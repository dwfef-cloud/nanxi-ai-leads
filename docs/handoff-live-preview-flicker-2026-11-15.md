# 实况大屏闪烁修复（2026-11-15）

后续视频错位与主界面缩放问题已在 `handoff-live-preview-layout-2026-11-15.md` 继续修复；该文档记录实际原生边界验收和整窗截图工具的限制。本文件的局部画面检查不代表整窗布局已通过。

用户反馈上一轮实况截图预览一直闪。原实现每 1.2 秒替换图片，图片解码与显示共用同一元素；原生视图也会重复接收相同的尺寸和缩放设置。本轮处理预览渲染，保留先前的停止控制和真实写操作门禁。

## 修改

- `ui/live-worker-preview.js`：新帧先在独立图片中完成解码，再一次性绘制到持续保留的 Canvas。等待、失败和过期帧都不清空旧画面；停止后尚未解码完成的旧帧不能恢复“执行中”。Canvas 尺寸不变时不重新设置尺寸，不重复清空。
- `ui/live-worker-preview.html`：使用 Canvas 显示；脚本独立加载，同源 CSP，仍是只读执行画面。
- `desktop/main.js`、`desktop/live-preview.js`：预览最多每 200ms 采样一次；慢帧期间跳过重复采样，不积压。仅尺寸或缩放实际变化时更新原生视图；空闲状态只推送一次。
- 这是约 5 帧/秒的只读预览，不代表原生视频帧率。
