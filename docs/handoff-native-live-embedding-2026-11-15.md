# 实况大屏恢复原生页面嵌入（2026-11-15）

最新状态：用户要求撤回自动裁切/放大，随后提供两张完整页面截图并确认将该显示设置用于全局。当前已实现共享完整页面布局、单账号铺满、多账号网格和批量恢复边界同步，详见文末与全局规定第15节。以下视频聚焦记录仅作历史留档。正式客户端尚需正常重启加载最新主进程代码。

## 用户要求与原因

用户要求恢复原有原生网页嵌入设计。此前大屏载入 `live-worker-preview.html`，把隐藏执行窗口截成 JPEG 再绘制到 Canvas；虽然像素来自实际页面，但大屏中无法直接操作平台网页。该路径现在已从正式 `desktop/main.js` 移除。

## 实现

- 新增 `desktop/worker-surface.js`：每个账号一个原生执行页面；初始挂在带 `paintWhenInitiallyHidden` 的隐藏 BrowserWindow，平台页关闭后台节流。后续聚焦修订采用 WebContentsView，见下节。
- `douyin_agent` 按原账号分区创建/复用该执行页面；所有原有读取、浏览、输入与停止脚本继续使用它的 webContents。账号登录、大屏也使用相同实例，没有复制页面或同步网址。
- 大屏挂载原生页面，收起后移回后台宿主；保持实际视口和缩放，避免收起时坐标变化破坏在途操作。重新挂载恢复容器坐标，不刷新页面。
- 删除备用平台预热标签页，避免又产生第二个同会话页面。创作聚合与消息聚合保留既有独立模块容器。
- 保留 CSS→DIP 换算、平台页缩放、原有前端窗口布局、日志和精确停止控制。
- 评论点赞原可见首帧门禁改为核对同一个实际页面在正确宿主可见且完成渲染，仍绑定 runId、停止标志及既有账号/目标/次数授权。
- 历史截图工具与测试兼容文件仍保留，但正式大屏不调用 `updateWorkerPreview`，不加载本地 Canvas viewer。
