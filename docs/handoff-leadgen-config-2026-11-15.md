## 本轮范围和运行边界

用户授权完善此前整理的评论获客任务设置。保留原有两栏表单、完整页面原生实况大屏、单账号和多账号布局；本轮未重启或终止用户客户端，未运行真实账号任务，没有发送评论、回复、私信，也没有点赞。

本轮不是全功能或平台真机验收。核心动作的配置、规划、确认和执行协议已经接线并做隔离回归；尚缺平台接线的选项会明确阻止启动。现有客户端需正常退出后重新打开，才能加载新版桌面主进程和后台；只刷新前端不够。不要强制结束用户的运行任务。

## 已实现的配置行为

| 设置 | 当前行为与边界 |
| --- | --- |
| 搜索关键词 | 中文/英文逗号、顿号、分号、空白和换行分词；引号保留带空格短语，JSON转义兼容；去重但不截断，最多200词，超限报错 |
| 全局与账号专属词 | 专属词完整传递；全局池已领取的词不再被拆开。本次只处理已领取词，后续词仍需重新准备、核对清单，不会未经确认自动发送 |
| 指定视频 | 读取完整抖音视频链接，先读视频元数据再生成计划；短链接仍须前端先解析 |
| 视频筛选 | 标题包含/排除、作者通配符、配置的视频发布时间，以及点赞/评论/收藏/分享数量阈值；缺数据不能当作满足条件 |
| 视频人设筛选 | 有有效智能体时独立判断；未绑定时明确报错，不能静默忽略 |
| 评论筛选 | 评论定位、本人及软件其他账号、作者排除、正文排除词、时间与IP地区；启用地区筛选时未知属地跳过 |
| 意向模式 | 关键词、全部、独立AI判断；未绑定智能体的AI意向按页面约定回退关键词，并明确提示 |
| 主评与回复正文 | 各自的目标、风格、人设提示生效；自定义模板一行一条、随机选一条；支持昵称替换和随机表情后缀 |
| 未绑定智能体 | 显式未绑定的账号使用模板正文；模板缺失或无效时阻止。表单里的账号绑定与实际启动的逐账号绑定分开校验，避免误报 |
| 五类核心动作 | 视频点赞、视频主评、评论点赞、回复、私信进入同一精确确认清单；动作、账号、视频、评论、作者、正文和收件人必须对应 |
| 数量与频率 | 总互动上限1–100、每视频评论赞/回复数量、私信总限、视频点赞概率、每词视频读取目标、视频停留和互动间隔均参与规划/执行 |
| 可用评论不足 | 每视频读取最多60条当前可定位评论；筛选或数量不足按实际清单执行，不制造达标统计 |
| 线索入池 | 保存来源关键词、视频、原评论、账号和意向依据；排除词评论可作为普通线索保留，但不作为互动对象；保留人工跟进状态 |
| 重复防护 | 单账号重复主评/回复/点赞阻止；私信按账号与收件人去重，跨视频也只规划一次；结果待确认停止且不重发 |
| 多账号主评 | 默认已主评视频跳过。明确允许其他账号继续时仍串行占用同一视频，未知回执不能被另一账号越过 |
| 暂停/继续/停止 | 准备阶段提供“停止准备”；执行阶段提供暂停、继续、停止；间隔可打断；视频停留有独立取消心跳，不占住串行指令队列 |
| 进度与统计 | 保存已处理数、剩余数和状态检查点；失败、跳过、未知均不算成功，未知结果保留待核验；跨进程重开需重新确认剩余清单 |
| 多账号结果 | 每账号独立授权文件、运行结果和统计，再汇总任务；刷新不再误判活跃任务；异常中断的准备记录过宽限期归位，不能自动恢复发送 |
| 回查确认 | 认证页面的准确回执可补记对应账号、运行和汇总主评数；保留原运行失败/停止状态，不重复提交，不覆盖另一账号结果 |
| 清单核对 | 较长批量清单分页完整呈现；全部核对后才授权。配置和正文绑定，确认后修改配置不能复用旧授权 |
| 实况大屏 | 未改变现有布局。视频点赞新增可见大屏就绪检查；评论点赞与发送动作保留原有就绪检查 |

## 明确未接通，不能写成完成

- 来源：关注列表、推荐页、喜欢列表、话题。
- 官方搜索的非默认排序、发布时间、视频时长、搜索范围、内容形式。自定义的视频发布时间筛选是读取元数据后筛选，与官方搜索控件不同。
- 自动关注、分享用户主页、分享原评论、主页首作互动、关注/私信前养护。
- 主评/回复附图、GIF、@账号、无文字发送。
- 全局关键词池自动连续领取下一个词并自动继续真实动作；当前仅确认本次领取词对应清单。
- 进程重启后自动恢复未完成发送；检查点用于可追溯和重新核对，不代表自动续发。
- 私信实际平台DOM和协议仍需获授权后的真实账号校准；离线适配器通过不等于平台发送通过。
- 作品发布保持本轮范围之外。

以上开关仍可保存既有配置；选中尚未接通选项会在“执行设置检查”和启动校验中给出中文原因。关闭父动作后，不让隐藏附件残留值阻止无关动作。
