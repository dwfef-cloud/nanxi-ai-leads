## 三之二、设计边界（本版明确不做，不计入空白）

| # | 功能 | 为什么不接 |
|---|---|---|
| ACC-5 | 导入/导出抖音登录态 cookie 会话，并测试代理 | 会话 cookie 导入/导出等于把平台登录态在设备间搬运，涉账号安全与平台风控，本版明确不做；代理测试同理 |
| CL-1 | 查看评论点赞任务的执行结果 | 评论点赞=对平台内容做写操作，本产品不做代操作；没有点赞任务自然也没有执行结果，页面按「未开通」呈现 |
| CL-2 | 启动一条评论点赞任务 | 点赞是平台写操作，触达即风控；本版不实装执行引擎，只保留未开通提示 |
| ST-1 | 在设置里打开/关闭硬件加速、调界面缩放、清缓存 | 硬件加速 / 界面缩放 / 清缓存都是 Electron app API，HTTP 桥没有这个权限；正确落点在桌面壳 ipcMain，不属于后端接线范围 |
| UP-1 | 检查更新并下载安装 | 更新由桌面壳 electron-updater 负责（下载/校验/安装），后端只提供版本号；安装动作也不能由后端触发 |
